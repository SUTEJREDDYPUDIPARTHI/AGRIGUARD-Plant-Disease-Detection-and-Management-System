AGRIGUARD 🌿

AGRIGUARD is a real-time plant disease detection system built using Convolutional Neural Networks (CNN). Designed to support farmers and agricultural professionals, this web-based application allows users to upload plant leaf images for instant and accurate disease diagnosis. It also provides treatment suggestions and generates detailed disease reports to help manage plant health more effectively.

Features 🚀

- 🌱 Real-Time Disease Detection: Upload plant leaf images and receive instant predictions.
- 🧠 CNN-Powered Model: Utilizes deep learning for accurate classification of various plant diseases.
- 💊 Treatment Suggestions: Recommends possible treatments based on detected diseases.
- 📊 Disease Reports: Generates comprehensive reports for better decision-making and record-keeping.
- 🌐 Web-Based Interface: User-friendly interface accessible via browser without installation.

Tech Stack 📦

- Frontend: Flask
- Backend: Python, TensorFlow/Keras
- Model: Custom-trained CNN for image classification
- Other Tools: OpenCV, NumPy, Pandas

Installation 🛠️

1. Clone the Repository
git clone https://github.com/SUTEJREDDYPUDIPARTHI/AGRIGUARD-Plant-Disease-Detection-and-Management-System

2. Install Dependencies
pip install -r requirements.txt
